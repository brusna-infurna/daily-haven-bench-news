# Daily Haven Bench News

Monitor diário de notícias de wellness residences, membership clubs, longevidade, lifestyle e lançamentos no Brasil e no mundo, pra alimentar os times de parcerias, marketing, vendas e clube do Haven.

- `radar-data.json`: todas as edições (uma por dia), fonte de verdade.
- `build.py`: gera `index.html` a partir do JSON.
- `index.html`: dashboard publicado no GitHub Pages.

Atualizado automaticamente por uma tarefa agendada no Claude, toda manhã.
